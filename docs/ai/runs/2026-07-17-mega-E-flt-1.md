  "implements AgentsRepository"` across `test/` and `integration_test/` before
  considering the change done — `flutter analyze` on a narrow file scope will
  not catch this.

  backend addition beyond what the dispatch described as pre-merged. Both are
  additive wrappers over data/endpoints the merged backend already computes

  correct way to satisfy the issue's literal acceptance criteria. Flagged here
  for visibility since the dispatch implied Flutter-only file ownership.
