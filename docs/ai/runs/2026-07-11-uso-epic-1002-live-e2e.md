# USO epic + #1002 AgentRunner fix — live-verified

AgentRunner bug (#1002) and the release ABI fix (#1023). Orchestrated as 6
parallel worktree workstreams off one run branch; integrated in dependency order.

## Root cause of #1002 (the "AgentRunner bugging out")

The proven #1002 fix (commit `009823585`) was stranded on the **stale PR #1005
branch and never re-landed on main** — the re-land (#1020) brought only
#999/#1000/#1003/#1004. So beta.18.42 (built from main) still fails every
headless/scheduled run with the bogus "model produced no output".

opencode sessions are **directory-scoped**: the headless path created the
session under `effectiveCwd` (`cwd ?? process.cwd()`) but called
`prompt`/`listMessages`/`abortSession` with the raw (undefined) `cwd`, so the
engine looked in its default instance, found no session, and returned empty
parts. Interactive works because the WS path passes a consistent cwd.
Fix: use `effectiveCwd` for all three post-creation engine calls, and extend
boot recovery (`resetStaleRunning`) to free `'starting'` orphans (not only
`'running'`).
