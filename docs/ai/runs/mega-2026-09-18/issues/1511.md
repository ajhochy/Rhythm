# #1511 Electron Agents: replace confusing archive/density checkbox rows with clear view options [OPEN] labels=enhancement,frontend

## User report

In the Electron Agents session sidebar, the standalone **Archived sessions** and **Compact rows** checkboxes consume prominent vertical space without making their purpose clear.

AJ's feedback on the September 17 screenshot: “these tick boxes are wasted space. I dont even know what they're for.”

The screenshot shows each small checkbox on a line above its label, leaving two large, awkwardly separated controls above the session list. The current markup places both labels directly inside `.rail-filters` in `apps/web/src/components/SessionRail.tsx`.

## Current meaning

- **Archived sessions** toggles `archivedOnly`: it changes which sessions are listed; it does not archive a session.
- **Compact rows** toggles `compact`: it changes the list's display density.

These are occasional view preferences, not primary actions that need two permanent rows in the rail.

## Proposed change

Remove the two standalone checkbox rows from the main rail and put these capabilities in a compact, clearly labeled **View options** menu, ideally alongside the existing sort control.

- Present archive access as **View archived sessions** or an equally explicit Active/Archived list choice. Explain that it opens the archive rather than changing a session's archived state.
- Present density as **Row spacing: Comfortable / Compact** (or equivalent plain-language labels), with a brief explanation that compact fits more sessions into the list.
- Keep the current view/density state visible in the menu. When the archive is active, clearly identify the archived view and provide an obvious return to active sessions so filtering is never silently hidden.

Preserve the capabilities and preference persistence while reclaiming the vertical space; do not delete access to archived conversations.

## Acceptance criteria

- [ ] The Agents rail no longer reserves two standalone rows for the Archived sessions and Compact rows checkboxes.
- [ ] Both capabilities are discoverable through one clearly labeled, compact control near the existing list controls.
- [ ] Copy distinguishes viewing archived sessions from archiving/deleting a session, and explains density in plain language.
- [ ] The selected archive/density options are apparent; archived view has a clear label and return path.
- [ ] Existing sorting, archive filtering, density behavior, account-scoped persistence, and session selection remain correct.
- [ ] Keyboard and screen-reader users can open the menu, identify/change the selected options, and return focus to its trigger on close. Narrow layouts and 200% zoom do not split controls from their labels or clip options.
- [ ] Before/after Electron screenshots at the same window size demonstrate recovered list space and readable labels; AJ reviews the result.
