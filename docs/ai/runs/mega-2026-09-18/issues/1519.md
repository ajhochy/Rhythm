# #1519 Electron Integrations: adopt the Agents Tasks list-and-inspector design [OPEN] labels=enhancement,frontend

## Request
Bring the Electron Integrations tab into the unified Agents → Tasks visual and interaction pattern.

## Design reference
AJ explicitly selected **Agents → Tasks** as the visual and interaction reference (not the main Tasks tab). The shared pattern is:
- A compact item list on the left: a simple title and one short subtitle/metadata line.
- Selecting a row opens that item's full details and functions in the main inspector to its right (the center workspace when the app navigation is visible).
- Keep the list for selection; put detailed content, editing, and item-specific actions in the inspector.
- Use the same typography, spacing, row selection, inspector structure, and action placement across these pages. Preserve each domain's actual functions.

## Current context
Integrations currently combines provider/account summaries, an inspector, and provider-specific settings. Unify the list and inspector while retaining the distinct consent and connection behavior for each provider.

## Acceptance criteria
- [ ] List each provider/account or existing integration section on the left with a clear name and short identity/connection-status subtitle.
- [ ] Selecting an entry shows connection details, supported settings, and related actions in the main inspector.
- [ ] Keep connect/reconnect/disconnect and sync actions, calendar selection, Gmail signals, Planning Center filters, and applicable import tools discoverable in the appropriate inspector context.
- [ ] Keep broad assistant Google access distinct from narrower integration consent. Selection must not initiate OAuth, sync, disconnect, or import.
- [ ] Mouse and keyboard selection update the correct inspector, with visible focus and selected state.
- [ ] Long titles/metadata, empty results, loading, errors, and read-only access remain usable; resizing does not clip essential controls.
- [ ] Refresh and existing deep links preserve or restore the correct selection; missing/deleted items produce a clear state rather than stale details.
