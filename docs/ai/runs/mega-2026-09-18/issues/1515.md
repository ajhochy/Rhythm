# #1515 Electron Facilities: adopt the Agents Tasks list-and-inspector design [OPEN] labels=enhancement,frontend

## Request
Bring the Electron Facilities tab into the unified Agents → Tasks visual and interaction pattern.

## Design reference
AJ explicitly selected **Agents → Tasks** as the visual and interaction reference (not the main Tasks tab). The shared pattern is:
- A compact item list on the left: a simple title and one short subtitle/metadata line.
- Selecting a row opens that item's full details and functions in the main inspector to its right (the center workspace when the app navigation is visible).
- Keep the list for selection; put detailed content, editing, and item-specific actions in the inspector.
- Use the same typography, spacing, row selection, inspector structure, and action placement across these pages. Preserve each domain's actual functions.

## Current context
Facilities has separate live and fixture implementations and already includes some inspectors. Unify the actual Electron/live page rather than only polishing a fixture view.

## Acceptance criteria
- [ ] Provide compact selectable room/space and reservation lists within the existing meaningful sections or filters.
- [ ] Show the selected room or reservation details, editing controls, and relevant actions together in the main inspector.
- [ ] Preserve room management, reservation editing, recurrence/group operations, conflict/availability feedback, and automation-reservation management. Keep calendar/schedule context available without making it the only route to details.
- [ ] Mouse and keyboard selection update the correct inspector, with visible focus and selected state.
- [ ] Long titles/metadata, empty results, loading, errors, and read-only access remain usable; resizing does not clip essential controls.
- [ ] Refresh and existing deep links preserve or restore the correct selection; missing/deleted items produce a clear state rather than stale details.

## Required evaluation
Select rooms and reservations, inspect/edit with isolated data, verify recurrence/group and conflict safeguards, and compare the live-rendered layout with Agents → Tasks. Include rendered checks for keyboard focus, long titles, narrow windows, loading/empty/error states, and consistent appearance alongside Agents → Tasks. Existing domain behavior must continue to pass.

## Dependencies / related work
Use the common contract from #1513; coordinate shared component/styles rather than creating another page-specific pattern. Related readability work: #1509.

## Safety / out of scope
This issue requests Electron/React UI work. Preserve current permissions, confirmations, persisted data, and API contracts. No production data repair, migration, deployment, or automatic execution of user actions is authorized by this design request. Live UI must not silently fall back to fixture-only behavior. Validate any mutations with isolated test data. The mobile bell issue (#1510) and separate Agents sidebar issues (#1511, #1512) remain separate.
