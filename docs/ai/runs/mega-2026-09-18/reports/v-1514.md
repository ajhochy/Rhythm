# Decisions

- Used dependency injection for the existing `ToolFrame` so Agent Settings could move out of `ToolWorkspace.tsx` without moving or duplicating the shared frame; rejected a circular import and rejected copying `ToolFrame`.
- Made the fixture Agent Settings consume the same section model so the required fixture-mode contract can exercise the primitive; rejected retaining the old two-button fixture markup.
- Kept Accounts read-only in Electron because the sessions gateway exposes account status but no authorization/credential mutation; rejected renderer-held credentials.
- Exposed runtime health checks but left URL mutation/restart as an explicit gap because no responsible desktop gateway exists; rejected a renderer-local preference.
- Exposed MCP connect/disconnect/remove only. Add, credentials, and OAuth browser completion remain explicit gaps until a safe host handoff exists; rejected arbitrary command/URL and secret forms.
- Kept profile editing in `#/profiles` because #1523 owns the per-profile editor; rejected duplicating profile mutations inside Agent Settings.
