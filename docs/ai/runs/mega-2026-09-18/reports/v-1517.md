# Decisions

- Used one unified grouped rail instead of retaining separate Templates/Active mode rails; rejected a page-specific fork of the shared primitive.
- Stored prefixed row IDs in `projectId` while treating existing `/projects/templates/:id[/instances]` and `/projects/instances/:id` paths as selection adapters; rejected route replacement on every row click.
- Kept creation/refresh/completed filtering in the primitive toolbar and all item-specific actions in the inspector; rejected action buttons inside listbox options.
- Used the existing browser confirmation pattern for unsaved inline step edits; rejected silently discarding the draft.
- Left `apps/web/src/gateway/projects.ts` unchanged because the existing API surface already supports every preserved action; rejected an unnecessary gateway contract change.
- Kept the template's Active Projects subview as linked-project summaries because active projects are directly selectable in the shared left group; rejected duplicating a second actionable project rail inside the inspector.
