# Decisions

- Stored raw rule IDs in `automationId` and prefixed only shared row IDs; rejected exposing the test-oriented `automation-rule-` prefix in deep links.
- Retained source grouping and added shared search; rejected recreating the old action-heavy cards or adding a page-specific list variant.
- Kept preview available during read-only access while disabling edit, toggle, trigger/resync, delete, create, and direct-save controls; rejected disabling inspection with mutation controls.
- Preserved a deleted selected ID so the primitive shows `Item not found`; rejected silently selecting another rule and showing unrelated details.
- Kept the live gateway and API contract unchanged; rejected gateway churn because this workstream only changes selection and presentation.
