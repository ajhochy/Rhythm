# Summary

Adopted the shared `ListInspector` and `useSelectedId('threadId')` for fixture and live Messages. Conversation rows now contain a title plus one preview/metadata line, while the transcript, composer, and item actions live in the inspector. Selection is URL-backed and no longer marks a thread read. Deleted or unknown selections use the primitive's not-found state. Added the required rendered test coverage for selection, states, actions, responsive layout, zoom, accessibility, and long-history composer containment.

# Decisions

- Used raw domain ids in the `threadId` URL parameter and prefixed only shared row ids with `messages-thread-`; rejected replacing legacy `/messages/:id` links.
- Made selection update only URL/local inspection state; rejected the old automatic mark-read mutation on row selection.
- Left a deleted selected id in place so the primitive shows its not-found state; rejected silently selecting a fallback conversation.
- Kept the existing action popover inside the inspector; rejected duplicating item actions in list rows.
- Preserved live mark-read/unread and send capabilities; rejected adding rename/delete gateway methods because the API exposes no corresponding routes.
