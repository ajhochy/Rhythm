# Decisions

- Used six independent Planner day widths so changing one boundary preserves the other day columns and each preference survives reopening.
- Used `resizeEdge="end"` for Tasks and Rhythms because the detail pane owns the saved size.
- Included Hermes after the route audit found an additional fixed status/workspace boundary; it uses separate wide and compact storage keys.
- Normalized the account service's `{ authorizeUrl }` response to the UI gateway's `{ authorizationUrl }` shape.
- Added optional account operations to `SessionGateway` because the shared interface has broad consumers and fixtures should remain compatible.
- Treated Behavior, Keybindings, and runtime mutation as unsupported until HTTP owners exist: GET/PATCH `/agent-settings/behavior`, GET/PATCH `/agent-settings/keybindings`, GET/PATCH `/opencode/runtime`, and POST `/opencode/runtime/restart`.
