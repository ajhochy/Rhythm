# Decisions

- Chose `settingsSection` as the persisted hash key; rejected component-only selection because refresh/deep links must restore the inspector.
- Split keyboard/safety editing into an explicit local Save boundary so section changes can confirm before discarding; rejected silently persisting every keystroke because it cannot represent an unsaved edit.
- Kept theme changes immediate and account/device scoped, preserving existing behavior.
- Kept the four related destinations as navigation-only rows; rejected embedding duplicate editors in main Settings.
- Used one shared member dataset in separate Members/roles and Facilities Manager inspectors; rejected crowding all controls into one row or inspector.
- Left `post-m1-phase-1-settings.redspec.ts` unchanged because it covers Agent Settings/session behavior and contains no old main `/settings` markup assertion.
