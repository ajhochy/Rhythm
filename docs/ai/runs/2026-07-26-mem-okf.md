## Notes

- The live gate refuses any base other than `http://127.0.0.1:4098`, requires
  `RHYTHM_LIVE_E2E_ISOLATED=1`, and verifies `DB_PATH` plus the vault live
  beneath the explicit sandbox root.
- No provider, OAuth, PCO, email, or other external credentials are required.
  WebSocket provenance is recorded before any model-provider execution.
- The real built Rhythm MCP server is exercised over stdio JSON-RPC and pointed
  at the sandbox agent URL; a non-secret dummy token satisfies its startup
  contract without contacting production.
- Automatic ambient-session attribution is exercised using the SDK id returned
  by a real sandbox session mapping.
- The optional one-hop link-expansion feature is asserted default-off. The
  sandbox launch explicitly pins it false so an ambient shell override cannot
  change the test contract.
- Mechanical consolidation has no public HTTP or MCP trigger. Consolidation
  source-union/collision rewriting, retiree backlink rewriting, log/revert
  behavior, and byte-for-byte restoration remain covered by the real
  filesystem + SQLite integration suites. The live gate exercises the public
  merge-on-capture collision path.
- Corrected cross-link behavior is public-smoked where reachable: escaped and
  inline/fenced-code lookalikes remain byte-preserved, only a real live link
  creates a generated backlink, and deleting that target leaves a tolerated
  dangling link that is not expanded into WS provenance. Retiree-link rewrite
  itself remains integration-only because consolidation has no public trigger.
- `log.md` is intentionally process-local/best-effort. The live test polls its
  externally observable writes and warning output; it does not assume the HTTP
  response waits for the audit append.
- The log privacy probe puts a credential-shaped `sk_live_…` token on the first
  content line and rejects both the literal token and its slug-normalized form,
  covering path/title leakage as well as body omission.
- Exact `(by, at)` lifecycle replay remains an integration-test boundary: both
  public HTTP and MCP lifecycle surfaces assign `at` server-side and expose no
  caller-controlled stable timestamp, so a live caller cannot deterministically
  submit the same pair twice.
- All temporary sandbox and launcher artifacts were removed. No production DB
  or production listener was mutated.
