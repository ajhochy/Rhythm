## Coverage and source boundaries

- Eight P0 families: `tasks`, `sessions`, `conversation`, `navigation`, `rhythm-primary-chat`, `coordinator-multi-run`, `approval-expiry`, `router-first-prompt`. The router promotion is explicitly user-authorized; global router/account changes remain forbidden. Other rows are deliberately deferred at the required inventory checkpoint. A family includes its listed main path and edge contracts; three tests per family is the minimum, not permission to omit listed gaps.
- `coordinator_coding_*`, signed `coordinator.workflow.start`, bounded propose/start tools, Docker evaluator and the finite `workflow` purpose are retired by #1612 / `d03bf90e`. Their historical receipts must not become present-tense tests. Current behavior is workflow-orchestrator multi-run tracking.
- Mobile-only claims (including Research A/B packets, model/chat controls and project creation), physical audio/banner output, native Dayflow/Hermes/Colony and off-LAN relay delivery need separate deterministic/native/device fixtures. A packaged renderer cannot qualify them by showing a tab.
- Engineering changes (provider auth/version gate, bootstrap parity, snapshot/attachment bounds, log reduction, build storage/signing, qualification isolation) are grouped with the feature whose outcome they protect. They do not justify running builds, changing settings, injecting credentials or modifying original repositories in this task.
- Inventory quotes are evidence of claims, not proof that the installed build fulfills them. Org Reviewer context pagination must be reconfirmed from its latest run before codifying its acceptance criteria.
- Existing broad `packaged-smoke.spec.ts`: KEEP runtime/startup and basic task selectors; REDO as feature evidence where it only checks page visibility or lacks backend readback/guaranteed cleanup. Its real-model case must obey the new model opt-in. Fixture suites remain useful selector examples, not live feature proof.
- Every recon record will include installed version, source base, observed method/path/status/shape, sanitized UI outcomes and limitations; never persist auth headers, private collection payloads or a raw transcript.
