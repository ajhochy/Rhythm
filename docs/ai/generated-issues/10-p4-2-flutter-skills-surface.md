# P4-2: Flutter skills surface: draft badge + demote/delete

## Goal

Build a Flutter `agent_skills` feature (view/controller/repository/data/model) that lists skills with a DRAFT badge for draft-status skills (especially `source='teacher-escalation'`), and provides demote (→ delete) and publish actions. Wire the controller into `main.dart`, make the UI accessible from a nav row.

## Context

Phase 4's Flutter surface allows users to inspect and curate draft skills generated by the extractor and teacher-escalation. Draft skills (especially from teacher-escalation) are flagged with a badge; users can demote (delete) or publish (promote to published status) them. This gives humans control over the self-improvement loop.

- NEW `apps/desktop_flutter/lib/features/agent_skills/` (full feature: view, controller, repository, data, model)
  - `views/agent_skills_view.dart` (main list view with badge + actions)

  - `repositories/agent_skills_repository.dart` (data layer)

## Acceptance Criteria

- [ ] **Agent skills feature structure:**
  - `AgentSkillModel` (Dart class) with fields: id, title, description, when_to_use, steps, tags, confidence, status, source, uses, created_at, updated_at
  - `fromJson`/`toJson` helpers
  - `AgentSkillsDataSource` with methods:
    - `getSkills(): Future<List<AgentSkillModel>>`
    - `updateSkill(id, {status?, ...}): Future<AgentSkillModel>`
    - `deleteSkill(id): Future<void>`
  - `AgentSkillsRepository` wrapping the data source
  - `AgentSkillsController` (extends `ChangeNotifier`) with:
    - `skillsList: List<AgentSkillModel>`
    - `status: SkillsStatus` (enum: idle/loading/error)
    - `loadSkills(): Future<void>` (fetches via repository)
    - `publishSkill(id): Future<void>` (PATCH to set status='published')
    - `deleteSkill(id): Future<void>` (DELETE)
    - Error handling + logging

- [ ] **View layer (`agent_skills_view.dart`):**
  - Stateful widget that watches `AgentSkillsController` via `context.watch()`
  - Displays a list of skills in cards or rows:
    - Skill title, description (snippet), source
    - DRAFT badge for `status='draft'` (especially prominent for `source='teacher-escalation'`)
    - Confidence score/visual indicator
  - Action buttons per skill:
    - **Publish:** Changes status from 'draft' to 'published' (calls `controller.publishSkill(id)`)
    - **Delete/Demote:** Removes the skill (calls `controller.deleteSkill(id)`)
  - Loading state: show spinner while `status === loading`
  - Error state: display error message if `status === error`
  - Empty state: "No skills yet" message if list is empty

- [ ] **Badge styling:**
  - DRAFT badge: e.g., "DRAFT" in orange/amber color, rounded corner
  - Teacher-escalation badge or annotation: e.g., "⭐ Learned from failure" or extra color differentiation

- [ ] **Navigation wiring:**
  - Register `AgentSkillsController` in `main.dart` as:
    ```dart
    ChangeNotifierProvider<AgentSkillsController>(
      create: (_) => AgentSkillsController(repository: AgentSkillsRepository(...)),
    )
    ```
  - Add a nav item or row in `_agents_nav_column.dart` (or main nav) that points to `AgentSkillsView`:
    - Label: "Skills" or "Skill Library"
    - Route to skills feature when tapped

- [ ] **REAL-SURFACE widget test:**
