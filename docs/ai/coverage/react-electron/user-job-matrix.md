## Evidence and status rules

| Code | Existing test mechanism, not a result |
|---|---|
| F | Fixture/local renderer-state test; cannot prove persistence, real transport or engine behavior. |
| I | Intercepted HTTP/WebSocket (including tests/helpers named “live”); proves only assertions at that substituted boundary. |
| R-src | Source for a real-runtime test exists, but is unexecuted/unqualified on this candidate. Not runtime evidence. |
| P-src | Source for packaged-app checks exists, but is unexecuted/unqualified here; smoke mode is not normal installed startup. |
| U | Unit/component or mocked-service check; useful regression evidence only within its actual boundary. |
| none | No appropriate existing check mapped in this integration; not a claim that the repository has no tests. Owner must identify/write/discover a maintained contract before implementation. |

Required tiers are **R** (real API/persistence/fork/MCP behavior in E02-approved sandbox), **P** (installed signed candidate on mandatory Apple Silicon and Intel qualification legs), **H** (AJ/manual keyboard/VoiceOver/product journey), and **D** (manager documentation/provenance check). Supporting F/I/U never replaces R/P/H. All rows are currently **NOT_TESTED**, or **BLOCKED** where a mount/resource remains unknown. “NOT TESTED” is serialized as `NOT_TESTED`. A source-confirmed mount is reachability evidence, not a runtime outcome. No fixture, method, route, file name, declaration count, historical run or unexecuted test can yield PASS.

Every grouped row requires **each named action** and its deny/failure/reload behavior, not one representative click. Electron entries describe current visible entry or required destination, not a promise that it is already live; “required” is explicit when an entry is not established. Source references below resolve relative to repository root. UNKNOWN never means omitted. Latest shipped Flutter behavior/artifacts must be reconciled before every gate and before closure of each merged Flutter/shared behavior change.
