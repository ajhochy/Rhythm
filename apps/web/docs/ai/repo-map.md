# Repository map

- `src/App.tsx`, `src/components/Shell.tsx`: application routing and shell.
- `src/pages/*/index.tsx`: page behavior and deterministic fixture mutations.
- `src/pages/*/styles.css`: page-scoped presentation.
- `src/components/`: shared dialogs and task controls.
- `src/styles.css`: shared Rhythm tokens and component styles.
- `tests/pages/`: representative page journeys, responsive checks, and accessibility checks.
- `tests/contract/`: detailed deterministic endpoint and permission contracts.
- `dist/`: generated production output; do not edit by hand.
- `test-results/`: generated test artifacts; do not edit by hand.
